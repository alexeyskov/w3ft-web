# Проверка приложенного Warcraft_III.zip

Исследован локальный `resources/Warcraft_III.zip`. В нём 40 записей, суммарно
1 300 911 339 байт после распаковки. Инструменты не выполняют EXE/DLL.

Подготовленная установка находится в `var/game`, полный машинный отчёт —
`var/reports/game.json`. Эти локальные производные включают коммерческие игровые
файлы и не нужны в исходном репозитории.

```sh
python3 tools/prepare_game.py
python3 tools/inspect_game.py
python3 -m unittest discover -s tests -p test_game_tools.py -v
```

Распаковщик отказывается перезаписывать существующую установку. Перед записью он
проверяет пути, символьные ссылки, специальные файлы, повторяющиеся имена без учёта
регистра, конфликты файл/каталог, шифрование и суммарный размер. Файлы читаются
потоком во временный каталог и перемещаются в назначение после завершения.

## Реальная версия и загрузка

`game.dll` и `war3.exe` содержат ресурс VERSIONINFO с **1.26.0.6401**. Строка
ProductVersion — `Version 1.26.0`. Эти данные сами по себе не подтверждают
обозначение «1.26b» из задания; привязка порта должна опираться на хеши, а не
название архива. Лаунчер `Frozen Throne.exe` имеет собственную версию 1.5.0.0.

игровую логику.

## Зависимости, которые должен реализовать порт

Статические импорты `game.dll` включают 17 библиотек: COMCTL32, WINMM, KERNEL32,
comdlg32, ADVAPI32, WININET, Storm, ijl15, MSVCR80, WSOCK32, mss32, OPENGL32,
IMM32, USER32, GDI32, SHELL32 и ole32.

- 112 ordinal-импортов Storm.dll требуют точного ABI и работы MPQ/файловой
  системы. В Storm.dll 459 непустых экспортов.
- 110 импортов Miles Sound System включают потоки, музыку, 3D-звук, callbacks,
  декодирование ASI/ADPCM, MIDI/XMI/DLS. Сам Mss32.dll содержит вторую исполняемую
  секцию `MSSMIXER`; обход только `.text` потеряет код.
- 50 OpenGL-импортов включают fixed-function pipeline, матрицы, освещение,
  текстуры, fog и WGL. В ASCII-строках `game.dll` также есть `d3d8.dll` и
  `Direct3DCreate8`. Это свидетельство динамической загрузки Direct3D 8;
  статическая таблица импортов не является полным перечнем graphics API.
- 25 ordinal-импортов WSOCK32 требуют реализации сетевой семантики игры.
  Веб-комнаты и транспорт байтов сами по себе не подключают этот Winsock ABI.
- Есть Win32 threads/TLS, events/mutexes/semaphores, IO completion ports,
  memory protection, filesystem, registry, window messages и C++ exceptions.
- `MSVCR80.dll`, импортируемая игрой и Storm.dll, не лежит в архиве как отдельный
  файл. Присутствующие MSVCR120/MSVCP120 не заменяют её ABI. На Windows зависимость
  может обеспечиваться установленным runtime; для WASM нужны собственные
  реализации этих функций или перенос соответствующей библиотеки.

Ни у этих пяти основных PE не обнаружены TLS data directory или delay-import
directory; это не отменяет вызовы TlsAlloc/TlsGetValue и LoadLibrary/GetProcAddress.

## Карты и кампания

Каталог `Maps/` в ZIP пуст; отдельных `.w3m`, `.w3x` и `.w3n` нет. Архив содержит
`war3.mpq`, `War3x.mpq`, `War3xLocal.mpq`, `War3Patch.mpq` и девять MPQ с роликами.
Этот инспектор не распаковывает содержимое MPQ и не делает выводов о числе
встроенных карт. Для каталога серверных карт нужны отдельно предоставленные
карты или проверенная индексация/извлечение MPQ.

## Граница подтверждённого результата

Разобраны 18 PE-файлов (включая Miles plugins и редактор) без ошибок. 12 тестов
проверяют разбор PE/imports/VERSIONINFO и безопасную распаковку. Анализ не
подтверждает запуск игры, кампании, звука, роликов или сетевого матча в браузере.
Для этого нужны рекомпиляция машинного кода, совместимый Win32/graphics/audio
runtime, подключённый сетевой ABI и проверка непосредственно в игре.
