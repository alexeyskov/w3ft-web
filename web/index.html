Оригинальный Warcraft III: The Frozen Throne в браузере. Игровой код перекомпилирован в WebAssembly, графика работает через WebGL 2, звук — через Web Audio.

Кампания, сражения и карты выбираются в самой игре. Сохранения остаются в браузере, а с друзьями можно играть через LAN-лобби.

Поддерживаются русская и английская версии Warcraft. Язык игры совпадает с выбранным языком сайта.

Вопросы и сообщения об ошибках можно оставить в GitHub Issues или в Discord.

Исходный код на GitHub.

Оформление лаунчера, инструменты статической перекомпиляции и CPU-функции адаптированы из nfsu2-web (th0mk), основанного на NFSU2Recomp авторства Talha Müderrisoğlu. Заимствованные файлы взяты из закреплённой MIT-версии.

Справочная реализация формата MPQ — StormLib. IP-геолокация — DB-IP (CC BY 4.0).

LAN-лобби

«Играть» без выбранного лобби добавляет вас в первое общее лобби вашего языка, где есть место (до 200 игроков). Можно войти в любое лобби: игроки с разным языком игры играют вместе. Можно и создать своё. В Warcraft откройте «Локальная сеть»: один игрок создаёт матч, остальные присоединяются.

На сенсорном экране: касание — щелчок, долгое касание или касание двумя пальцами — правая кнопка мыши, движение двумя пальцами — прокрутка карты, щипок — масштаб. Кнопка с клавиатурой открывает экранную клавиатуру; чат в игре открывается её клавишей Enter.

Клавиатура и мышь работают внутри окна игры. Остальные команды — стандартные команды Warcraft III. Чтобы выйти из полноэкранного режима, удерживайте Esc.
