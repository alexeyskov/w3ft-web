Оригинальный Warcraft III: The Frozen Throne в браузере. Игровой код перекомпилирован в WebAssembly, графика работает через WebGL 2, звук — через Web Audio.

Кампания, сражения и карты выбираются в самой игре. Сохранения остаются в браузере, а с друзьями можно играть через LAN-лобби.

Поддерживаются русская и английская версии Warcraft. Язык игры совпадает с выбранным языком сайта.

Вопросы и сообщения об ошибках — в GitHub Issues.

Независимый фанатский проект. Не связан с Blizzard Entertainment и не одобрен компанией. Запуск со своей копией игры.

Исходный код — на GitHub.

Оформление лаунчера, инструменты статической перекомпиляции и CPU-функции адаптированы из nfsu2-web (th0mk), основанного на NFSU2Recomp авторства Talha Müderrisoğlu. Заимствованные файлы взяты из закреплённой MIT-версии.

Справочная реализация формата MPQ — StormLib. IP-геолокация — DB-IP (CC BY 4.0).

LAN-лобби

«Играть» без выбранного лобби добавляет вас в первое общее лобби вашего языка, где есть место (до 200 игроков). Можно войти в любое лобби: игроки с разным языком игры играют вместе. Можно и создать своё. В Warcraft откройте «Локальная сеть»: один игрок создаёт матч, остальные присоединяются.

Изменения

07.11.2026

  • Язык страницы по умолчанию — по стране: русский для стран СНГ, английский для остальных.
  • Когда все общие лобби языка заполнены, «Играть» открывает дополнительное; оно закрывается, когда его покидает последний игрок.
  • Выход из сетевой игры через меню («Выйти из миссии», «Выйти из программы») больше не завершается ошибкой, повтор сохраняется.
  • Первая загрузка в 3 раза меньше: WebAssembly и файлы программы передаются сжатыми (gzip), до главного меню — около 77 МБ вместо 240.
  • Разрешение по умолчанию — 1280 × 960; на выбор от 800 × 600 до 2048 × 1536.
  • В английской версии можно писать по-русски: в чате, имени игрока и названии игры.

06.11.2026

  • Компактная страница запуска, параметры и полноэкранный режим.
  • Публичные LAN-лобби и вход по коду.
  • Сохранения в браузере с резервным копированием и восстановлением.
  • Настройки графики игры на вкладке «Игра», включая работающую гамму.
  • Счётчик «Сейчас играют».
  • Общие лобби на 200 игроков: «Играть» сразу добавляет в первое лобби, где есть место.
  • Английская версия игры: язык игры совпадает с языком сайта, общие лобби разделены по языкам.
  • Частота кадров: «Авто», 30, 60 или 120.
  • Данные игры на устройстве: предзагрузка, удаление и сброс настроек.
  • Закрытие страницы сразу освобождает место в лобби.
  • Полноэкранный режим без панели: курсор захватывает игра, выход — удерживать Esc.
